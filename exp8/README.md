# FSD Experiments

This repository contains Full Stack Development experiments:

- **exp3.1.1**: Login Form App (React/Vite)
- **exp3.1.2**: Protected Routes with Authentication (React Client + Node Server)
- **exp3.1.3**: Role-Based Access Control (Admin/User Dashboards)
- **Experiment_3.1.3**: Additional Role-Based Access Control implementation

## Setup

1. Clone the repo
2. For each experiment with client/server:
   - Client: `cd expX.X.X/client && npm install && npm run dev`
   - Server: `cd expX.X.X/server && npm install && npm run dev`
